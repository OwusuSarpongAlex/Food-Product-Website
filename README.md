A simple food ordering system built with HTML, CSS, JavaScript (Frontend) and PHP + MySQL (Backend).
It allows users to browse food items, add them to cart, and place orders, while the admin can manage menu items and view customer orders.

🚀 Features

User-friendly food browsing interface

Add to cart & checkout system

Order history tracking

Admin panel to manage food items & view orders

Secure database with MySQL

🛠 Technologies Used
Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL
